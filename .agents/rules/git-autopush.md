# Git Auto-Push Rule

After modifying, adding, or deleting any project code files to fulfill a user request:
1. Stage all changes: `git add -A`
2. Commit with a meaningful, concise summary of the changes: `git commit -m "<concise description of changes>"`
3. Push to the remote tracking branch: `git push origin main`
4. Confirm to the user that changes were committed and pushed to GitHub.
